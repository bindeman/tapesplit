# Code of Conduct

tapesplit follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in every project space (issues, pull requests, code review, and any other discussion) and whenever you represent the project in public. The text at that link is the authoritative version; this page is a short summary.

## In short

- Be kind and respectful. Assume good intent, give and accept feedback gracefully, and own your mistakes.
- Keep the focus on what is best for the project and the people who use it. Many of them are working with irreplaceable family footage.
- No harassment, discrimination, trolling, insults, or sexualized language or imagery.
- Do not publish anyone's private information without permission. In this project that includes other people's home videos, faces, names, and transcripts.

## Reporting and enforcement

If you see or experience behavior that breaks these standards, report it privately to the maintainer, Phillip Bindeman, using the contact details on his GitHub profile: <https://github.com/bindeman>. If you cannot reach him that way, open a private report from the repository's Security tab (**Report a vulnerability**) and say it is a Code of Conduct report. Please do not use public issues or pull requests for conduct reports.

Reports are reviewed and investigated promptly and fairly, and the reporter's privacy is respected. The maintainer applies the Covenant's Enforcement Guidelines (correction, warning, temporary ban, permanent ban) in proportion to the behavior.
